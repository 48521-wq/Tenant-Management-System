Step 1: Start TMS Backend
  cd backend
  npm install
  npm start
  → Running on http://localhost:5000

Step 2: Serve TMS Frontend
  cd ..  (back to TMS root folder)
  npx serve -l 5500
  OR: python3 -m http.server 5500
  → Running on http://localhost:5500

Step 4: Put TMSBlackBoxTest.java in Maven project
  Place in: src/test/java/com/tms/blackbox/TMSBlackBoxTest.java

Step 5: Run Selenium Tests
  mvn test -Dtest=TMSBlackBoxTest
