  SETUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════

STEP 1 — Install backend dependencies (first time only):
  cd backend
  npm install

STEP 2 — Start the backend server:
  cd backend
  npm start
  
  OR double-click: START_SERVER.bat

STEP 3 — Open the frontend:
  Open index.html in a browser (use VS Code Live Server or 
  any local server like http-server)
  
  Frontend URL: http://localhost:5500
  Backend URL:  http://localhost:5000/api

═══════════════════════════════════════════════════════════════
  NEW API ROUTES ADDED
═══════════════════════════════════════════════════════════════

GET/POST  /api/complaints        — Tenant files, Admin views all
PUT       /api/complaints/:id/status — Admin updates status

GET/POST  /api/maintenance       — Tenant submits, Admin views
PUT       /api/maintenance/:id/status — Admin updates status

GET/POST  /api/payments          — Tenant records, Admin views
DELETE    /api/payments/:id      — Admin removes

GET/POST  /api/leases            — Tenant signs, Admin views
DELETE    /api/leases/:id        — Admin removes

GET       /api/notifications              — list notifications for the logged-in user
GET       /api/notifications/unread-count — unread badge count
POST      /api/notifications              — Admin/Landlord sends (tenant blocked)
PUT       /api/notifications/mark-all-read — marks visible notifs as read
DELETE    /api/notifications/:id          — Admin removes

Notifications now SAVE to MongoDB Atlas (previously they only lived in the
browser's localStorage and never reached the database or other devices).
