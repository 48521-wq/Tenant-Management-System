═══════════════════════════════════════════════════════════════════
  TMS v4 — Tenant Management System  |  HOW TO RUN
═══════════════════════════════════════════════════════════════════

  Full-stack rental property management application.
  Frontend: HTML + CSS + Vanilla JS
  Backend:  Node.js + Express + MongoDB Atlas
  Auth:     JWT + Google OAuth 2.0 (GSI)

═══════════════════════════════════════════════════════════════════
  PREREQUISITES
═══════════════════════════════════════════════════════════════════

  - Node.js v16 or higher   →  https://nodejs.org
  - A modern web browser    →  Chrome, Firefox, or Edge
  - Internet connection     →  Required for MongoDB Atlas

  No local MongoDB installation needed — the database is hosted
  on MongoDB Atlas (cloud).

═══════════════════════════════════════════════════════════════════
  SETUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════════

  STEP 1 — Install backend dependencies (first time only):

    cd backend
    npm install

    This installs: express, mongoose, bcryptjs, jsonwebtoken,
    cors, dotenv, google-auth-library

  ─────────────────────────────────────────────────────────────────

  STEP 2 — Start the backend server:

    cd backend
    npm start

    OR on Windows, simply double-click:
    → START_SERVER.bat

    You should see:
      🚀 TMS Backend running on http://localhost:5000
      ✅ MongoDB Atlas Connected: ...

  ─────────────────────────────────────────────────────────────────

  STEP 3 — Open the frontend:

    Option A (recommended): Use VS Code Live Server extension
      Right-click index.html → "Open with Live Server"
      URL: http://localhost:5500

    Option B: Use http-server (npm install -g http-server)
      http-server .
      URL: http://localhost:8080

    Option C: Open index.html directly in the browser
      Works for most features. Google OAuth may be limited
      on file:// protocol in some browsers.

  ─────────────────────────────────────────────────────────────────

  URLs summary:
    Frontend  →  http://localhost:5500  (or your Live Server port)
    Backend   →  http://localhost:5000
    API Base  →  http://localhost:5000/api
    Health    →  http://localhost:5000/api/health

═══════════════════════════════════════════════════════════════════
  API ENDPOINT REFERENCE
═══════════════════════════════════════════════════════════════════

  Auth
    POST   /api/auth/register          Register new tenant or landlord
    POST   /api/auth/login             Email + password login
    POST   /api/auth/google            Google OAuth login / signup
    GET    /api/auth/me                Get current user profile
    PUT    /api/auth/profile           Update profile fields

  Users  (admin only)
    GET    /api/users                  List all users
    PUT    /api/users/:id/block        Toggle block / unblock
    PUT    /api/users/:id/verify       Mark user as verified
    DELETE /api/users/:id              Delete user

  Properties
    GET    /api/properties             List all (with filters)
    GET    /api/properties/my          Landlord's own listings
    GET    /api/properties/:id         Single property
    POST   /api/properties             Create listing (landlord)
    PUT    /api/properties/:id         Update property
    PUT    /api/properties/:id/model3d Save 3D model config
    DELETE /api/properties/:id         Delete property

  Complaints
    GET    /api/complaints             List (scoped by role)
    POST   /api/complaints             File complaint (tenant)
    PUT    /api/complaints/:id/status  Update status (admin)
    DELETE /api/complaints/:id         Delete (admin)

  Maintenance
    GET    /api/maintenance            List (scoped by role)
    POST   /api/maintenance            Submit request (tenant)
    PUT    /api/maintenance/:id/status Update status (admin)
    DELETE /api/maintenance/:id        Delete (admin)

  Payments
    GET    /api/payments               List (scoped by role)
    POST   /api/payments               Record payment (tenant)
    DELETE /api/payments/:id           Delete (admin)

  Leases
    GET    /api/leases                 List (scoped by role)
    POST   /api/leases                 Sign lease (tenant)
    DELETE /api/leases/:id             Delete (admin)

  System
    GET    /api/health                 Server health check

═══════════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

  ❌ "Cannot connect to server"
     → Make sure the backend is running (npm start in /backend)
     → Check that port 5000 is not in use by another process

  ❌ "MongoDB connection error"
     → Check your internet connection (Atlas is cloud-hosted)
     → Verify MONGODB_URI in backend/.env is correct

  ❌ Google Sign-In not working
     → Use VS Code Live Server instead of opening file:// directly
     → The Google Client ID is pre-configured for localhost

  ❌ Blank screen or JS errors
     → Open browser DevTools (F12) → Console tab for details
     → Make sure backend is running first
